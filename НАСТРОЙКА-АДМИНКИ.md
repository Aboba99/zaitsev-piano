# Что осталось сделать руками (5–10 минут)

Код готов и лежит в приватном репозитории https://github.com/Aboba99/zaitsev-piano.
Эти шаги я не могу сделать сам: нужны твой вход в аккаунты, подтверждение доступа и секретный ключ.
Названия пунктов в интерфейсах Netlify и GitHub могут немного отличаться.

## 1. Подключить репозиторий к сайту на Netlify

Сейчас сайт `rainbow-begonia-0c5e54` залит вручную, перетаскиванием папки. Его надо привязать к GitHub, чтобы после каждой правки в админке сайт пересобирался сам.

1. https://app.netlify.com → сайт `rainbow-begonia-0c5e54` → **Site configuration** → **Build & deploy** → **Link repository** (или «Link to Git»).
2. Выбрать **GitHub**, разрешить Netlify доступ и выбрать репозиторий `Aboba99/zaitsev-piano`.
3. Настройки сборки (обычно подставятся сами из `netlify.toml`):
   - Branch: `main`
   - Build command: `npm run build`
   - Publish directory: `_site`
4. Нажать **Deploy**. Через 1–2 минуты сайт соберётся уже из репозитория.

## 2. Ключ для входа в админку (GitHub OAuth App)

1. https://github.com/settings/developers → **OAuth Apps** → **New OAuth App**.
2. Заполнить:
   - Application name: `Мастерская Зайцева — админка`
   - Homepage URL: `https://rainbow-begonia-0c5e54.netlify.app`
   - Authorization callback URL: `https://rainbow-begonia-0c5e54.netlify.app/api/callback`
3. **Register application** → скопировать **Client ID** → **Generate a new client secret** → скопировать секрет.
   Секрет никому не отправляй и не вставляй в чаты.
4. Netlify → сайт → **Project configuration** → **Environment variables** → добавить две переменные:
   - `GITHUB_CLIENT_ID` — Client ID;
   - `GITHUB_CLIENT_SECRET` — секрет (отметить как secret).
   Затем **Deploys** → **Trigger deploy**, чтобы переменные подхватились.

   Вход обслуживают наши функции `netlify/functions/auth.mjs` и `callback.mjs`. Встроенный OAuth-провайдер Netlify не используется: его форма в ноябре 2026 отправляла пустые поля.

## 3. Доступ для Веры (или того, кто будет править сайт)

1. Вера регистрируется на https://github.com (бесплатно).
2. Репозиторий → **Settings** → **Collaborators** → **Add people** → её логин → права **Write**.
3. Вера принимает приглашение из письма.

## 4. Проверка

1. Открыть `https://rainbow-begonia-0c5e54.netlify.app/admin/` → **Войти через GitHub**.
2. Поменять цену у любого пианино → **Опубликовать**.
3. Через 1–2 минуты цена должна поменяться на сайте.

Инструкция для владельца: `https://rainbow-begonia-0c5e54.netlify.app/admin/help.html`.

## Если поменяешь адрес сайта

Например, на `zaitsev-piano.netlify.app` или свой домен. Тогда обнови:
- `site_url` и `display_url` в `src/admin/config.yml`;
- Homepage URL в OAuth App на GitHub;
- адрес в `src/robots.txt` и `src/sitemap.xml`, там сейчас стоит `example.ru`.
